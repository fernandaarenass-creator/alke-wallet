# 💳 Alke Wallet

Proyecto desarrollado como parte del módulo de Frontend, cuyo objetivo es simular una billetera digital básica.

La aplicación permite al usuario:
- Iniciar sesión
- Visualizar saldo
- Enviar dinero
- Gestionar contactos
- Ver movimientos simulados

Este proyecto fue realizado con tecnologías básicas de frontend y almacenamiento local.

---

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- Bootstrap 5
- JavaScript (Vanilla JS)
- LocalStorage (para persistencia de datos)

## 🚀 Funcionalidades principales

- Login de usuario (simulado)
- Visualización de saldo
- Envío de dinero
- Agenda de contactos
- Autocompletado de contactos
- Uso de modales para mensajes de confirmación

Los datos se almacenan utilizando `localStorage`, por lo que no se requiere backend.
